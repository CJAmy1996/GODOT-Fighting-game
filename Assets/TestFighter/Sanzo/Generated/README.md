# Generated Sanzo sprites

`crouching_heavy_kick/` contains the six original transparent sweep frames and
is the live source used by Sanzou's importer.
`crouching_heavy_kick_normalized/` is an unused archive of the reverted cleanup. It was
scaled from the median of Sanzou's crouching attack groups, remapped to the exact
source-frame palette, kept on a 320Ã—384 transparent canvas, and aligned to sandal
baseline y=249. The sandals use the established silver-gray/tan ramp rather than
the generated black artifact. The trousers use only the four canonical charcoal
values, and exposed skin uses six broad values with isolated micro-shading removed.

`sanzo_crouching_heavy_kick_frames.tres` previews the original sequence at 10 FPS.
`sanzo_crouching_heavy_kick_sheet_normalized.png` is the archived corrected contact sheet.
The chroma-key sheet and full-resolution pose sources remain available for future
corrections or additional in-between frames.
